For the 3D build

Proportions

2:3 cover. Thickness about 6.5% of the width (10px at 150px). Every book is the same size, whatever its length.

Light

One warm key light from the upper left. Page edges show on the right, the cloth hinge on the left.

Shadow

A soft contact shadow cast back and to the right. It stays on the ledge when the book lifts.

Motion

Lift on hover 6px, on select 14px, 220ms ease-out. With reduced motion: no lift, the amber mark only.

Text stays live

Title and name are real text over the cover, never baked into a texture, so they stay sharp, searchable and readable by screen readers.

Cost

Shared cloth texture and geometry, colors as parameters. No per-book images. If WebGL is unavailable or slow, render this CSS version.
