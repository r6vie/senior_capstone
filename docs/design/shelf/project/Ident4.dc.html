What we borrow

  • Everything is built from three shapes (circle, square, triangle) and three inks, so the page reads as composition, not decoration.
  • Lowercase geometric type set tight, one diagonal black bar for the call to action, thin rules on a visible grid.
  • Shapes overprint, so every colour pair makes a third; the paper stays warm and unbleached.
